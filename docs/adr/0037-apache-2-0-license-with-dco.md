# ADR-37: Apache-2.0 license with DCO

- Status: Accepted
- Group: ADR-37 to ADR-53 (third round, 2026-10-31)

## Context

explicit patent license; contributions under the same license without an additional contract (§5), no trademark rights (§6) ([apache2] VERIFIED); FSL and BSL do not meet OSD item 6 ([osd], [bsl] VERIFIED); AGPL deters companies that want to operate it themselves (DERIVED); without a CLA, relicensing is only possible with everyone's consent, which is intended

## Decision

License **Apache-2.0 with DCO**, no CLA, no open core (O16 decided)

## Alternatives

MIT; AGPL-3.0; FSL, BSL, Sustainable Use; CLA

## Consequences

The decision is applied in the documents listed under Source.
