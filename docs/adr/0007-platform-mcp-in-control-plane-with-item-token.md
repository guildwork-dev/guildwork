# ADR-07: Platform MCP in the control plane with item token

- Status: Accepted
- Group: ADR-01 to ADR-36

## Context

no credential in the sandbox that can do more than one item; blocker of the reviewers

## Decision

Platform MCP in the control plane with item token

## Alternatives

MCP sidecar in the sandbox

## Consequences

No separate list of affected documents is recorded for this decision; the affected documents are referenced in Context and Decision.
