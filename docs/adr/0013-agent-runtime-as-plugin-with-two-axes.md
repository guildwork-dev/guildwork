# ADR-13: AgentRuntime as a plugin with two axes

- Status: Accepted
- Group: ADR-01 to ADR-36

## Context

Modularity of the runtime is a project goal (README section 1); reference Pullfrog ([pullfrog] VERIFIED)

## Decision

AgentRuntime as a plugin with two axes (harness times credential)

## Alternatives

Claude Code as the only execution

## Consequences

No separate list of affected documents is recorded for this decision; the affected documents are referenced in Context and Decision.
