# ADR-27: CI-only topology only as eval and offline mode

- Status: Accepted
- Group: ADR-01 to ADR-36

## Context

without ledger, policy, and user limits, the limits per layer would be missed in live operation

## Decision

Topology "CI only without control plane" only as eval and offline mode

## Alternatives

Stage 1 as CI only (secure-quality)

## Consequences

No separate list of affected documents is recorded for this decision; the affected documents are referenced in Context and Decision.
