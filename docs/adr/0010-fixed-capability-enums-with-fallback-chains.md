# ADR-10: Fixed capability enums with fallback chains

- Status: Accepted
- Group: ADR-01 to ADR-36

## Context

typed, testable, honest deactivation

## Decision

Fixed capability enums with `native`, `fallback`, `none` and fallback chains, every fallback step audited

## Alternatives

String flags (PR-Agent), optional methods (Kodus)

## Consequences

No separate list of affected documents is recorded for this decision; the affected documents are referenced in Context and Decision.
