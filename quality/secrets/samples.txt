# Synthetic credential samples. Every value has the real shape of its
# credential type, so the secret rules must find it, but none is a real
# credential: each contains the marker EXAMPLE, and the GitHub values carry no
# valid checksum. Values must not contain the gitleaks stopword
# abcdefghijklmnopqrstuvwxyz (in any case), or gitleaks drops the finding.
#
# Users of this file:
#   .gitleaks.toml       allowlists exactly these values (regex ^<value>$)
#   test_gitleaks.py     scans them with the allowlist removed; every value must
#                        be found by the gitleaks rule named in column 2
#   packages/core        redaction tests (0-E01-T04, 0-E08-T01) use the same
#                        values, column 1 names the redaction pattern
#
# Format: one sample per line, three fields separated by whitespace:
#   <redaction pattern id> <gitleaks rule id> <value>
# Lines starting with # and blank lines are ignored.
#
# Formats and where they were checked (retrieved 2026-11-01); details in
# docs/quality/toolchain.md, section "Secret scanning":
#   (Comments name the Anthropic kinds without the sk-ant- prefix, so that
#   the rule anthropic-credential-any does not find this comment.)
#   api03, admin01   API key and Admin API key: 93 characters [A-Za-z0-9_-]
#       plus "AA", as in the default rules anthropic-api-key and
#       anthropic-admin-api-key of gitleaks 8.30.1; the Anthropic Admin API
#       documentation names the admin prefix
#   oat01, ort01     Claude Code OAuth access and refresh tokens; the shape is
#       not documented by the vendor and copied from the API key
#   ghp_, gho_, ghu_, ghs_, ghr_     prefix from the GitHub documentation; 30
#       Base62 characters plus a 6 character CRC32 checksum, 40 in total,
#       from the GitHub engineering blog on the token formats
#   github_pat_                      prefix from the GitHub documentation;
#       82 word characters as in the gitleaks rule github-fine-grained-pat
#       (the vendor documents no length)
#   ghs_<app id>_<JWT>               stateless installation token, rolled out
#       from 2026-04-27 (GitHub documentation and changelog 2026-05-15)
