# Guildwork

Guildwork is a modular, self-hostable agent platform for the software lifecycle: triage, planning, architecture, coding, pull request review, QA and fixing, each as a separate service that can be switched on or off on its own. Integrations (source hosting, ticket systems, agent runtimes, model providers, external analyzers) are plugins; storage, secrets and cloud identity are drivers, so every installation runs on its own infrastructure.

## Status

Early development. There is no release yet, and no interface is stable. Plugin and service interfaces are `v1alpha1` until stated otherwise (see [SUPPORT.md](SUPPORT.md)).
