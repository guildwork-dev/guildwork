# ADR-34: No AGPL, EE, or noncommercial code in the product

- Status: Accepted
- Group: ADR-01 to ADR-36

## Context

License purity of the product (ADR-37, [12](../architecture/12-open-source-and-project.md) section 2.4)

## Decision

No AGPL, EE, or noncommercial code in the product (Kodus, Sweep, OpenHands `enterprise/` only as an idea); adopted parts only under licenses of the allowlist with a provenance line

## Alternatives

Adopt code

## Consequences

No separate list of affected documents is recorded for this decision; the affected documents are referenced in Context and Decision.
