# ADR-23: Data path per repo class enforced

- Status: Accepted
- Group: ADR-01 to ADR-36

## Context

Blocker of the reviewers; which providers offer an EU data path is in the matrix [01](../architecture/01-plugin-interfaces.md) section 11.4 ([an-residency] VERIFIED; Vertex EU regions for Claude unverified)

## Decision

Data path per repo class enforced at load time and at provider resolution

## Alternatives

Data path only documented

## Consequences

No separate list of affected documents is recorded for this decision; the affected documents are referenced in Context and Decision.
