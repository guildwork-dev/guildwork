# ADR-32: Commands as text mentions with a configurable handle

- Status: Accepted
- Group: ADR-01 to ADR-36

## Context

Provider facts ([adf], [linear-agents], [gl-duo] VERIFIED)

## Decision

Commands as text mentions with a configurable handle, native mentions where available (Linear, Jira ADF, GitLab service account)

## Alternatives

text only

## Consequences

No separate list of affected documents is recorded for this decision; the affected documents are referenced in Context and Decision.
