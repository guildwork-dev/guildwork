# ADR-53: Planning docs in German, public docs in English from publication

- Status: Accepted
- Group: ADR-37 to ADR-53 (third round, 2026-10-31)

## Context

contributors worldwide; the reference project translated on the day it was made public; until then planning runs in German

## Decision

**Planning docs in German, public docs in English from publication** (O21 decided: English); research files are not translated, but marked as "dated, not binding" or remain private

## Alternatives

everything in German; English immediately

## Consequences

The decision is applied in the documents listed under Source.
