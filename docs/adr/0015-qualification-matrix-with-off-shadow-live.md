# ADR-15: Qualification matrix with off, shadow, live per service

- Status: Accepted
- Group: ADR-01 to ADR-36

## Context

The level of the standard as a measurement, not as a claim

## Decision

Qualification matrix, `off`, `shadow`, `live` per service

## Alternatives

Eval only as a rollout gate

## Consequences

No separate list of affected documents is recorded for this decision; the affected documents are referenced in Context and Decision.
